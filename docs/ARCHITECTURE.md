# Architecture

Static PWA, no framework, no runtime dependencies, no backend.

```
app/
  index.html        shell + all CSS (theme variables in :root)
  app.js            whole app, split in sections
  lang/*.json       39 flat dictionaries, en.json is the source of truth
  fonts/, fonts.css self-hosted Baloo 2 + Nunito (latin, latin-ext, cyrillic)
  icons/            PWA icons (any + maskable)
  manifest.webmanifest
  sw.js             cache-first service worker (asset list generated by tools/build.mjs)
tools/              Node scripts with compact output (also used by AI agents)
```

## app.js sections
| Section | Role |
|---|---|
| i18n | `LANGS`, `detectLang()`, `setLang()`, `t(key, params)`. Weekday/month names and number formats come from `Intl`. |
| state | single `state` object in `localStorage` (`turnotto.v1`): `staff`, `leaves`, `settings`, `plans`, `current`. |
| SCHEDULER | `check()` validates one slot against every rule; `generate()` runs a randomized greedy 90 times and keeps the best; `repair()` fills holes by moving one shift; `analyze()` computes coverage, hours and warnings. |
| VIEWS | `home`, `organico`, `ferie`, `turni`, `storico`, `regole`, `info`: functions returning HTML. Hash routing (`#turni`). |
| ACT | click handlers via `data-act` attributes (event delegation). |
| EXCEL | `XL.Book`: minimal OOXML writer (stored zip + styles) → real `.xlsx`; `exportXlsx()` builds 4 sheets; themes in `XT`. |
| wizard | first-run wizard (welcome, language, how-to, sample/empty data, privacy acceptance) and "what's new" wizard driven by `APP_VERSION` + `CHANGELOG`. |

## Scheduling model
Time is expressed in absolute minutes from the plan start (`day*1440 + minute`), so night shifts crossing midnight need no special case. A slot is valid when the person is available (days, time slots, excluded shifts, leave), it doesn't overlap, the merged consecutive block is ≤ max hours, rest before/after is ≥ minimum, weekly/fortnightly hours stay under caps and contract hours (+ overtime), and the longest free gap in the week / 14-day window stays ≥ the required rest.

## Updates
`tools/build.mjs` hashes all files into the cache name. A new deploy ⇒ new service worker ⇒ fresh files on next launch ⇒ the wizard shows the new `CHANGELOG` entries.
